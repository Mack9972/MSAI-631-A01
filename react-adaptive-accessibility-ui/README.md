# React Adaptive Accessibility UI

This project demonstrates accessibility principles through an adaptive React interface.

## What this UI showcases

- Semantic landmarks (`header`, `main`, `section`, `form`)
- Skip link for keyboard users
- High contrast mode toggle
- Large text mode toggle
- Reduced motion toggle
- Strong visible focus states
- Accessible form labels and helper text
- ARIA live announcement after form submit
- Descriptive alt text for media
- Responsive layout for mobile and desktop

## Run locally

```bash
cd react-adaptive-accessibility-ui
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
